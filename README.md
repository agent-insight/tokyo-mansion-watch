# 東京マンションウォッチ Ver.26

## 記事の「AIっぽさ」「テンプレ感」を抑える編集
- 記事冒頭に「山口より」を追加
- カテゴリ/エリアに応じて、山口本人の実務目線から入る導入文
- 本文の「です。」連続を一部コラム調・体言止めへ調整
- 「YAMAGUCHI VIEW」を廃止 → 「山口メモ」
- 「山口の見解」見出し → 「現場ではこう見ています」
- 「この記事を3行で」 → 「先に要点だけ」
- 「重要な数字」 → 「まず押さえたい数字」
- 「比較して見る」 → 「並べるとこうなります」

## 閲覧者に不要な制作側情報を整理
非表示/簡略化：
- 「出典確認」「事実と見解を分離」の帯
- 「この記事の読み方」
- 「記事の信頼性について」のサイドカード
- 「この記事が関係する人」
- 重複していた「この記事のポイント」
- 更新履歴は実際に複数更新がある記事だけ折りたたみ表示
- 情報源欄は「参考資料」に簡略化

## 残しているもの
- 一次情報へのリンク
- 確認日
- 関連記事
- 内部リンク
- 住宅ローン計算・市況データへの導線
- 山口プロフィール/相談導線
