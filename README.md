1. GitHub `agent-insight` アカウントで `tokyo-mansion-watch` リポジトリを作成
2. ZIPを展開し、中身をリポジトリ直下へアップロード
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. 公開URL: https://agent-insight.github.io/tokyo-mansion-watch/
