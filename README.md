## 公開アシスタント強化
publisher.html

3分ウォッチ1件から同時生成：
- LINE向け 300〜450字
- メール向け 450〜650字 + 件名
- Instagram向け 短文 + 要点3つ + 保存促進
- brief-data.js 差し込みコード

## 配信設計
distribution.html（noindex）

LINE = 会話
メール = 整理
Instagram = 入口

同じ文章をそのまま転載せず、媒体別に役割を変える。

## 運用
週次自動タスク
→ publisher.html
→ サイト掲載
→ LINE / メール / Instagramへ転用
