# 東京マンションウォッチ Ver.21

## スマホ表示の緊急修正
- ホームのプロフィールカードで画像下に巨大な水色余白が出る問題を修正
- プロフィール画像の高さを固定せず、16:10比率で安定表示
- 吹き出しが縦に異常に伸びる問題を修正
- tablet用grid/stretch指定をスマホで完全リセット
- ページ全体の横スクロールを防止
- ナビだけ横スクロール可能に変更
- ヘッダー・検索欄をスマホ幅へ最適化
- ヒーロー文字サイズ・余白をスマホ向けに調整
- LINE/メール固定CTAをsafe-area対応
- 相談帯の2ボタンをスマホで均等表示
- プロフィールページもスマホ向け1カラムへ再調整
- viewport-fit=coverを全ページに追加

確認推奨:
iPhone Safari/Chromeでトップページを再読み込みし、
プロフィール画像→吹き出し→プロフィール本文が隙間なく続くことを確認。
