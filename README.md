# 東京マンションウォッチ Ver.22 — PV / 被リンク強化版

## 新規実装
- `/tools/mortgage-calculator/`：住宅ローン返済シミュレーター
  - 借入額・金利・35/40/45/50年
  - 月々返済、総返済、総利息
  - 5/10/15年後残債
  - 別返済期間との比較
  - WebApplication構造化データ
  - GA4 `mortgage_calculator_use`
- `market-data.html`：東京23区・中古マンション市況データ
  - REINS 2026年8月度を基準に定点観測
  - Dataset構造化データ
  - REINS / 日本銀行 / 国交省 / 東京都への一次情報リンク
- トップに「役立つツール・データ」を新設
- 住宅ローン記事から計算ツールへ自動内部リンク
- 市況記事から市況データへ自動内部リンク
- エリア/テーマ別の文脈内部リンクを記事に自動追加
- 記事の外部情報源リンクを「公式・一次情報を確認」と明確化
- sources.html に公式データリンク集を追加
- 50年ローン親ページから計算ツールへ強い導線
- sitemap.xml 更新

## PV戦略
Google検索 → 記事 → 親クラスター → 無料ツール/定点データ → 関連記事 → 相談
の回遊導線を強化。

計算ツール・市況データは、他サイトやSNSから引用・紹介される「被リンク獲得資産」として運用する。
